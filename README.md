# Bottari

macOS 용 7-Zip 스타일 압축파일 관리자 (Swift / AppKit, macOS 12+). 압축 형식 처리는 macOS 내장 libarchive 를 사용합니다.

- zip, 7z, rar(읽기), tar, tar.gz/bz2/xz/zst, cab, iso, cpio 등 열기 (윈도우에서 만든 CP949 파일명 지원, 암호 zip 지원)
- 창에 드래그 앤 드롭 / Dock 아이콘에 드롭 / Finder "Open With" 로 열기
- 폴더 탐색, 이름·크기·수정일·속성·종류 목록, 정렬, 더블클릭으로 파일 열기, Finder 로 끌어서 꺼내기
- 압축 풀기: 현재 디렉토리 / 파일명 디렉토리 / 직접 지정, 선택 항목만 풀기, 테스트(무결성 검사)
- Finder 우클릭 ▸ 서비스(빠른 동작): Bottari로 열기, 여기에 압축 풀기, 폴더에 압축 풀기, 압축 풀기…

## 빌드 / 설치 (서명 없음, ad-hoc 만 적용)

    ./build.sh           # build/Bottari.app
    ./build.sh install   # /Applications 설치 + 서비스 등록

우클릭 메뉴가 안 보이면 시스템 설정 ▸ 키보드 ▸ 키보드 단축키 ▸ 서비스 ▸ 파일 및 폴더 에서 Bottari 항목을 켜세요.
다른 Mac 으로 복사해 "손상되었기 때문에 열 수 없음" 이 뜨면: `xattr -dr com.apple.quarantine Bottari.app`

## 풀 때의 안전 규칙

- 압축파일 안에서 `..` 로 밖을 가리키거나 지나치게 깊은 경로(256단계 초과)의 항목은 목록에서 숨기고(상태바에 개수 표시) 풀지 않습니다.
- 압축파일이 인터넷에서 받은 것(격리 속성 있음)이면 풀린 모든 파일·폴더에 같은 속성을 물려줘 Gatekeeper 검사가 유지됩니다.
- setuid/setgid 비트는 복원하지 않습니다. 장치 파일, FIFO, 소켓은 풀지 않습니다.
- 심볼릭 링크는 그대로 만들되, 링크를 통과해 압축 폴더 밖에 쓰지는 못합니다. 압축 안의 링크를 더블클릭해도 따라가 열지 않습니다.
- "기존 파일 덮어쓰기"를 끄면(기본) 이미 있는 파일은 건드리지 않고 건너뜁니다. 기존 폴더에 같은 이름의 폴더가 있으면 합쳐서 풀고, 파일↔폴더가 충돌하면 건너뜁니다.
- 암호가 틀리면 기존 파일을 지우거나 빈 파일을 만들지 않고 실패합니다. 풀다가 취소·실패하면 쓰다 만 파일은 지웁니다.
- 미리보기(더블클릭)와 Finder로 끌어내기용 임시 파일은 앱 종료 시 지우고, 비정상 종료로 남은 것은 다음 실행 때 하루가 지난 것부터 정리합니다.

## 알려진 한계

- RAR 은 읽기만 지원하고 압축 파일 만들기는 지원하지 않습니다.
- 항목별 "압축 크기" 열은 없습니다. (libarchive 가 제공하지 않음)
- 단일 압축 파일(`foo.txt.gz` 등)은 크기를 알 수 없어 크기 열이 비어 있습니다.
- 잘못된 암호로 풀면 암호화 파일 앞에 있던 빈 폴더가 만들어진 채 남을 수 있습니다.
- Apple Developer 서명이 없어 다른 Mac 에서는 처음 실행할 때 우클릭 ▸ 열기가 필요할 수 있습니다.
